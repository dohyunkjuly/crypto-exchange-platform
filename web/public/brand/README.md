# Brand

The four files the customer app shows. Replace them with yours; nothing else references a logo.

| File | Where it appears |
|---|---|
| `wordmark-dark.svg`, `wordmark-light.svg` | header, footer, sign-in pages, one per theme |
| `mark-dark.svg`, `mark-light.svg` | the square mark on the sign-in panel |

Any aspect ratio works: the wordmark is sized by height and keeps its own width. The name next to
them comes from `NEXT_PUBLIC_EXCHANGE_NAME`. The files here are a placeholder brand, as are the favicons in `web/src/app` (`icon.svg`,
`apple-icon.png`) ; the staff console's are the same two files in `admin/src/app`.
